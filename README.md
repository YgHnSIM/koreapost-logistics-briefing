# 우체국물류지원단 물류노동조합 · 원청 직접교섭 시정신청 조합원 브리핑

인천지방노동위원회 **인천2026교섭32** 원청 교섭요구 노동조합 확정공고 배제 시정신청 사건의 전체 경과(최초 교섭신청 ~ 제2차 보충의견서), 핵심 증거, 다가오는 3대 사업재편 대비 전략, 그리고 제출 서면 4종 전문을 조합원들에게 알기 쉽게 설명하기 위한 **모바일 최적화 정적 웹페이지**입니다.

## 주요 구성 (5단계 탭 전환형)
1. **01 핵심요약**: 진행 현황, 3대 핵심 포인트, 1장씩 넘기는 쉬운 3문 3답 카드 덱, 인라인 법률용어 해설
2. **02 전략·재편**: 2단계 직접교섭 전략 로드맵 & 우정사업본부 3대 사업재편(수도권 물류센터 신설·부천 우편집중국 폐국·부평 물류사업소 리모델링) 맥락
3. **03 4대논리**: 전 서면을 관통하는 4대 필승 논리 탭(`절차·금반언` / `한지붕·현장` / `인사·재무종속` / `로펌증거역탄핵`) 및 심층 법리 해설 모달
4. **04 5단계일지**: `2026. 10. 16.` 공고부터 `11. 16. 제2차 보충의견서`까지 아코디언 타임라인
5. **05 서면·공유**: 제출 서면 4종 전문 모달 뷰어(개인 연락처 비식별화 완료), 향후 절차 로드맵, 링크 복사·공유
