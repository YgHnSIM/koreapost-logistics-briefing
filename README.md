# 우체국물류지원단 물류노동조합 · 「이제 우본과 직접교섭이다」 원청 직접교섭 승소 브리핑

2026년 11월 23일 인천지방노동위원회 **인천2026교섭32** 심문회의에서 우체국물류지원단 물류노동조합이 대한민국(과학기술정보통신부 우정사업본부)과의 원·하청 단체교섭 참여 노동조합으로 인정받은 결정과, 2026년 11월 24일 공식 성명서 「이제 우본과 직접교섭이다」, 교섭 3대 출발점, 다가오는 3대 사업재편 대비 전략, 그리고 전체 서면(이의신청서 ~ 제2차 보충의견서 및 태평양 의견서(2) 요지·반박)을 조합원들에게 알기 쉽게 설명하기 위한 **모바일 최적화 정적 웹페이지**입니다.

- 배포 페이지: https://yghnsim.github.io/koreapost-logistics-briefing/

## 주요 구성 (5단계 탭 전환형)
1. **01 승소요약**: 2026. 11. 23. 인천지노위 인정 결정 현황, 3대 핵심 포인트, 공식 성명서 바로 보기, 1장씩 넘기는 쉬운 3문 3답 카드 덱, 인라인 법률용어 해설
2. **02 교섭·재편**: 1단계 교두보 달성 완료 및 **직접교섭 3대 출발점**(중앙 냉·난방/공조·환기, 휴게·노조공간 국유재산 사용승인, 국유 물류설비 안전 보강 및 부평 리모델링 사전 협의) + 우정사업본부 3대 사업재편(수도권 광역 물류센터 신설·부천 우편집중국 폐국·부평 물류사업소 리모델링) 대응 전략
3. **03 4대논리**: 승소를 이끈 4대 필승 논리 탭(`절차·금반언` / `한지붕·현장` / `인사·재무종속` / `태평양 1·2차 탄핵`) 및 심층 법리 해설 모달(사 제13~24호증 분석 포함)
4. **04 6단계일지**: `2026. 10. 16.` 공고부터 `11. 17.` 태평양 의견서(2), `11. 23.` 인천지노위 인정 결정, `11. 24.` 성명서 발표까지 아코디언 타임라인
5. **05 성명·서면**: 공식 성명서 및 주요 서면 6종 모달 뷰어(개인 연락처 비식별화 완료), 향후 직접교섭 로드맵, 링크 복사·공유
